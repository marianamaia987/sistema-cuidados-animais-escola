Requisitos do Sistema

Requisitos Funcionais

- Cadastro de animais

O sistema deve permitir cadastrar os animais que vivem ou frequentam a escola.

 - Identificação do animal

O sistema deve permitir registrar informações para identificar cada animal.

- Registro de alimentação

O sistema deve permitir registrar informações sobre a alimentação dos animais.

- Registro de vacinação

O sistema deve permitir registrar as informações de vacinação dos animais.

- Registro de cuidados

O sistema deve permitir registrar os cuidados realizados com cada animal.

 - Registro de datas

O sistema deve permitir registrar as datas em que os cuidados foram realizados.

 - Registro do responsável

O sistema deve permitir registrar quem ficou responsável pelo cuidado do animal.

 - Consulta

O sistema deve permitir consultar as informações cadastradas sobre os animais.

Requisitos Não Funcionais

- Facilidade de uso

O sistema deve possuir uma interface simples e fácil de utilizar.

- Organização

As informações dos animais devem ser apresentadas de forma organizada.

 - Desempenho

O sistema deve apresentar as informações cadastradas de maneira rápida.

- Compatibilidade

O sistema deve poder ser utilizado em computadores e dispositivos móveis.
